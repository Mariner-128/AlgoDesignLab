# 🧠 算法设计与分析学习平台 (AlgoLab)

一个**完全离线、开箱即用**的算法学习应用：覆盖《算法设计与分析》全部知识点（**13 章 71 个小节**），每个知识点均包含**理论精讲、可运行的 C/Python 案例代码（共 142 段，全部实测通过）、中等偏上难度练习题（240+ 道，含提示与详解）**，并内置科学的学习管理功能（进度跟踪、间隔复习、随机测验、错题本、搜索、速查表）。

---

## 🚀 快速开始

双击 **`启动学习平台.exe`** —— 自动检测 Python 并启动服务器，浏览器自动打开 `http://127.0.0.1:8765`，即可开始学习。

> 也可以手动启动：在项目目录运行 `python server.py`。
> 端口被占用时会自动顺延（8765 → 8766 …），以启动窗口打印的地址为准。
> 关闭方式：在启动窗口按 `Ctrl+C`，或直接关闭窗口。
> 需要 Python 3.8+ 且已加入 PATH；未安装请先安装并勾选 *Add Python to PATH*。

## 🔧 C 代码执行说明

平台自动探测 C 编译器，顺序：`tools\tcc.exe`（随附）→ 系统 `tcc` → `gcc` → `clang`。
首页启动时会提示当前可用的编译器。

- 已安装 **gcc / MinGW-w64 / TCC / LLVM** 且加入 PATH → 无需任何配置；
- 也可以把 TinyCC 的 `tcc.exe` 放进 `tools\` 目录（TinyCC 只有 1~2MB，[下载地址](https://download.savannah.gnu.org/releases/tinycc/)）；
- 无 C 编译器时：Python 案例仍可运行，C 案例会给出安装指引。

## ❓ 常见问题

- **浏览器打不开**：确认启动窗口显示的地址（端口可能顺延），手动访问该地址。
- **代码运行超时**：运行上限 15 秒（编译 25 秒），死循环会被自动终止。
- **数据丢失**：进度/笔记/错题保存在浏览器 localStorage 中；请在「学习统计 → 学习数据备份」中**定期导出备份**（JSON 文件），更换浏览器或清理数据后一键导入恢复；也可在那里清空全部学习数据。
- **内容更新**：章节内容在 `web/chapters/*.json`，参照 `SCHEMA.md` 修改后刷新页面即可生效。

## 📚 章节一览

1. **算法基础** — 复杂度度量、渐近记号、递归方程（代入/递归树/主定理）、正确性证明
2. **分治策略** — 二分、归并（逆序对）、快排、最大子数组、Karatsuba、最近点对
3. **动态规划** — 钢条切割、矩阵链、LCS、LIS、背包三兄弟、编辑距离、区间/状压 DP
4. **贪心算法** — 活动选择、Huffman、区间应用、Dijkstra、分数背包与证明方法
5. **图算法(上)** — 表示、BFS、DFS/拓扑排序、强连通分量
6. **图算法(下)** — MST、Bellman-Ford、Floyd-Warshall、最大流、二分图匹配
7. **高级数据结构** — 并查集、平衡树、堆、线段树、树状数组、哈希、B 树
8. **字符串算法** — 朴素、Rabin-Karp、KMP、Boyer-Moore、Trie/AC 自动机
9. **搜索与回溯** — 回溯框架、N 皇后、子集和、分支限界、迭代加深与 A*
10. **随机化算法** — 拉斯维加斯/蒙特卡洛、随机快排与选择、Miller-Rabin、随机化应用
11. **数论算法** — 扩展欧几里得、快速幂、素数筛、中国剩余定理、RSA
12. **摊还分析** — 聚合分析、记账法、势能法、动态表
13. **计算复杂性理论** — P/NP、归约、NPC 问题、NP 难与不可判定性
